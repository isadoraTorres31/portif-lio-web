# Portfólio Web

Portfólio responsivo construido com HTML, CSS e JavaScript. A experiência inclui:

- fundo animado com gradientes e elementos flutuantes;
- painel de desktop inspirado na interface do Windows;
- abas acessíveis para GitHub, currículo e projetos;
- navegação por teclado com arrow keys;
- layout responsivo para desktop e mobile;
- suporte a movimento reduzido.

## Executar

Abra `index.html` diretamente em um navegador, ou execute um servidor local:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Personalizar

Substitua os dados de exemplo em `index.html` e os links dos projetos, GitHub e currículo. O arquivo de currículo deve ser adicionado ao diretório e o link atualizado no painel correspondente.
