Estudo de desenvolvimento web

Portfólio pessoal.

Um site pessoal para apresentar meu perfil, meu currículo e meus projetos em uma interface interativa, responsiva e com identidade visual própria.

Meu papel Design e desenvolvimento
Tecnologias HTML · CSS · JavaScript
Tipo Projeto pessoal

Objetivo

Criar um espaço simples de navegar que reúna apresentação pessoal, acesso ao currículo em PDF e uma área para conhecer os projetos. O visual combina tons de azul, elementos translúcidos e referências a uma janela de computador.

O que foi desenvolvido

  • Layout adaptável para diferentes tamanhos de tela.
  • Navegação por abas para alternar entre GitHub, currículo e projetos.
  • Controle para ativar e pausar a animação de neve no fundo.
  • Cartões de projeto que levam às respectivas páginas de detalhes.
  • Atalho para abrir o currículo em PDF.
  • Suporte à preferência do sistema por movimento reduzido.

O que pratiquei

Estruturei páginas com HTML semântico, criei os componentes visuais e os estados responsivos em CSS e usei JavaScript para controlar as abas e as animações da interface.
